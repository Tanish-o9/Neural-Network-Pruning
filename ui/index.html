The Core Thesis: Why Sparse Weights Alone Don't Speed Up Inference

1 Dense GEMM Kernels

CPUs (AVX/SIMD) and GPUs (cuBLAS) rely on contiguous vectorized memory blocks. A dense matrix multiplication reads and computes 0.0 * x identically to 1.5 * x. Without specialized sparse hardware, zero weights take the exact same clock cycles.

2 Memory Bandwidth & Cache

Structured pruning deletes entire channels. This not only shrinks weight tensor memory, but also shrinks the feature maps (activations) between layers. This drastically reduces DRAM memory traffic and cache thrashing, yielding instant physical speedup.

3 Sparse Hardware (2:4)

NVIDIA Ampere+ GPUs have sparse Tensor Cores, but they strictly require a 2:4 pattern (exactly 2 zeros in every 4 contiguous weights). Arbitrary unstructured pruning cannot use this hardware without custom sparse indexing overhead.
